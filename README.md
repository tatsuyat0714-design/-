# 超次元サッカー ELEVEN LEGENDS

選手を育成し、必殺技を極め、**地区予選 → 全国大会 → 世界大会** を勝ち抜いて世界一を目指す、ブラウザで遊べる超次元サッカーゲームです。

## 遊び方

ビルド不要です。`index.html` をブラウザで開くだけで遊べます（スマホ対応）。
GitHub Pages を有効にすれば、そのままWeb公開もできます。

```bash
# ローカルサーバーで起動する場合（任意）
python3 -m http.server 8000
# → http://localhost:8000
```

セーブはブラウザの localStorage に自動保存されます。

## ゲームの流れ

| 大会 | 内容 |
|---|---|
| 地区予選 | トーナメント3試合 |
| 全国大会 ジャパンカップ | トーナメント4試合（決勝は40年無敗の帝王学園） |
| 世界大会 ギャラクシーカップ | グループリーグ3試合（上位2チーム突破）→ 準々決勝・準決勝・決勝 |

- トーナメントの引き分けはPK戦。
- 負けても3日間の特訓後に再挑戦できます（勝つまで何度でも）。

## 育成パート

- **トレーニング**（1日消費）：シュート / ドリブル / ディフェンス / キーパー / フィジカル / 必殺技特訓
- **休養**：コンディション回復。疲れたままだと練習効率も試合での力も下がります。
- **レベルアップ**でポジション・属性に応じた必殺技を自動習得（同じ種類の技は上位技へ進化）。
- **ショップ**：秘伝書で好きな必殺技を習得。大会が進むほど強力な秘伝書が入荷。
- **スカウト**：新しい選手を獲得（最大16人）。全国制覇後はライバルが、世界大会では「伝説の選手」が現れます。
- 必殺技は使うほど熟練度が上がり **「改」→「真」** に進化して威力アップ。

## 試合パート

- リアルタイムで進行。ボール保持者は自動でドリブルし、**ピッチをタップ**した方向へ進みます。
- **パス**：ボタン → 味方をタップ。**シュート**：どこからでも撃てます（遠いほど威力減）。
- 敵と接触すると**コマンドバトル**。必殺技（TP消費）か通常技を選択。
- シュートは「威力」vs「ブロック」vs「キーパー」の勝負。TPの配分が勝負の鍵。
- **オート**ですべて自動進行、**速度** x1〜x3 切替。

### 属性相性

火 → 林 → 風 → 山 → 火（矢印の先に強い：技の威力1.15倍）。選手と同じ属性の技は1.1倍。
